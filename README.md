A Python program that writes one short, funny rant about an everyday annoyance for [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun.

The rant:

> The self-checkout screamed 'UNEXPECTED ITEM IN THE BAGGING AREA' at a bag of apples. Apples. I scanned them. I bagged them. I did everything right, and this glowing robot still treated me like a fruit smuggler. Then it froze, beeped, and summoned a human — the one job it was built to replace. I paid full price to do its job and get accused of theft. Cashier, take me back.

## Run it

```sh
python3 main.py
```

It writes the rant to `/output/entry.txt` (under 400 characters, as the gate requires).
